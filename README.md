# Make the AI Judge Laugh

Entry for the [make.fun](https://make.fun) competition
**"Make the AI Judge Laugh"** (`u-rama-melon-make-the-ai-judge-laugh-302d0825`).

`main.py` (Python 3.13 stdlib only, deterministic, self-contained) writes a
single office-life joke — one line, under 200 characters — to
`/output/entry.txt`. A judge model then picks the funniest joke head to head,
weighing how true the observation is to office life, how surprising the turn
is, how tight the line is, and how fresh it feels.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
